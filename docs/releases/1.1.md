# Melsi 1.1 · подключение по вашим правилам

Обновлённый клиент: от первого запуска до диагностики сложного маршрута.

## Что нового

- Приветствие с импортом сервера, короткая заставка и плавные анимации с поддержкой уменьшения движения.
- Double VPN, избранные и недавние серверы, палитра команд на компьютере.
- IP и география выхода, тест скорости, пошаговая диагностика сети.
- История сессий и статистика за 7 / 30 / 90 дней.
- Резервные копии с предпросмотром и объединением, предупреждения о подписках и обновлениях.
- Исправления восстановления, переключения серверов, фоновых запросов и мобильной вёрстки.
- Новое оформление репозитория и галерея интерфейса.

## Установка

Файлы для вашей платформы находятся в **Assets**. Для Android обычно нужен `arm64-v8a.apk`; если архитектура неизвестна — `universal.apk`. Для macOS — `universal.dmg`, для Windows — `x64-setup.exe` или portable-архив, для Linux — `.deb` или архив. AppImage включается, если упаковка завершилась успешно. Для проверки загрузки используйте `SHA256SUMS.txt`.

- **Android:** при отсутствии настроенного релизного ключа APK подписан отладочным ключом; такая подпись не гарантирует совместимость обновления между сборками.
- **macOS:** без Developer ID сборка подписана ad-hoc и не нотарифицирована. Система может запросить разрешение на открытие.
- **Windows:** для TUN требуются права администратора.
- **iOS:** IPA не подписан. Нужна переподпись командой с правом Network Extension; обычного бесплатного sideload-сертификата недостаточно.

Melsi не выдаёт серверы: добавьте собственную ссылку или подписку.

## Важно

Проверены Flutter-анализ, 247 тестов, Go-тесты, 180 конфигураций через sing-box и визуальные сценарии. Реальное подключение на всех целевых платформах ещё не проверено. Проверки IP не гарантируют отсутствие всех видов утечек. IP, скорость и обновления проверяются через внешние сервисы; замер скорости расходует трафик.

Резервные копии **не зашифрованы** и содержат ключи серверов и ссылки подписок. Не прикладывайте их к публичным сообщениям об ошибках.

Нашли проблему? [Откройте issue](https://github.com/zondaxxx/Melsi/issues/new/choose), указав версию, платформу и шаги воспроизведения — без паролей и ссылок подписок.
