# Melsi · оформление

**Подключение по вашим правилам.** Спокойный интерфейс, понятные маршруты и контроль вместо громких обещаний.

- `cover.svg` — обложка README, 1280 × 640. Рядом хранится PNG для предпросмотра ссылок GitHub.
- `mark.svg` — плоская векторная версия существующего знака: щит и буква M.
- Иконка установленного приложения остаётся в `app/assets/icon/icon.png`; оформление репозитория не меняет её.
- Скриншоты в `docs/screenshots/` сняты из клиента с демонстрационными данными, без настоящих ключей.

Название пишется **Melsi**. Не растягивайте знак, не меняйте пропорции щита и оставляйте вокруг него свободное пространство. Кнопки, переключатели и выделение внутри клиента используют фирменный фиолетовый `#7053E8`, как и иконка.

Интерфейс тёмный — чистый чёрный, светлая тема — холодный графит. Шрифт встроенный Liberation Mono (метрика Courier, латиница и кириллица): он не загружается из сети. Углы прямые, без стекла и теней. Крупный заголовок приветствия один раз сжимает трекинг и останавливается; при уменьшении движения он появляется сразу.

Не используйте формулировки «полная анонимность», «нет утечек» или «ускоряет любое подключение»: клиент предоставляет инструменты, а результат зависит от сервера, маршрутов и платформы.
