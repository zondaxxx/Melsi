# Country borders

`countries.json` is Natural Earth 1:110m admin-0 countries (public domain),
reduced to exterior rings. Coordinates are rounded to 0.01°. Antarctica is
omitted. ISO codes use Natural Earth's `ISO_A2_EH` field so France and Norway
keep their codes.

Source: https://www.naturalearthdata.com/downloads/110m-cultural-vectors/

No map SDK. The home screen paints these rings directly.
